## 4. 各阶段详细任务

### P0：先充分复用，不先调用模型

1. 校验CURRENT、manifest及实际文件哈希，保存基图和代码/提示指纹。
2. 复用以下材料：v2完整图、原始全库 `units/`、旧质量核验与主审记录、实体 `enriched_pool.jsonl` 和身份候选、整合阶段的来源队列。核验结论只有在原文和处理语义兼容时才能复用；旧记录是数据资产，不能伪装成新模型缓存。
3. 对所有事实建立 `fact_id → 来源 → 端点 → 已有结论 → 本轮处置` 台账。分成：保留原状、纯登记/定位候选修正、继续开放表达、需要原文语义核验、证据/归属冲突待审。没有充分依据的类别暂存，不能靠raw=mechanism直接判断正确或错误。
4. 1,924条未映射事实逐条分流；已经映射的3,892条也做程序筛查，并从自动通过部分抽查，不只检查规则发现的问题。
5. 按原文块去重疑点，关联旧事实与实体候选。排除已解决项，避免同一原文在不同队列中重复发送。
6. 输出全部48篇状态及模型候选规模。1,998块队列用于找入口，不全部送模型，也不因新增节点缺边而强行建立关系。

### P1：先保证增量合并不会破坏ID

现有 `materialize.py` 按 `ent:<mention_id>`生成实体ID，而部分补充实体已有其他ID形式。关系补充前，应让物化器保留已存在的 `from_mention_id → entity.id` 映射，首次新增时才生成新ID；同步校验器的边派生检查。

新增事实、关系候选及条件修正写在独立补丁中。纯登记修正保留逻辑事实ID并记字段差异；语义改变、条件拆分或新增实验结果生成新事实ID，外置记录替代/拆分映射。旧记录仍可在旧快照中追溯，不能在同一ID下无记录改变含义。

最小测试覆盖：旧实体ID保留、新端点存在且同篇、边方向按角色、单对象测量不硬凑边、配位/吸附区分、互斥浓度拆分、语义类型保留、重复合并幂等、指纹失配拒绝、失败续跑只处理失败项。复用已有测试，不为格式调整扩大全套测试。

### P2—P4：关系和条件一起核验

每项关系同时检查：作用物/被作用对象、研究对象与比较对象、参与者角色、关系方向、条件归属、结果归属、原文证据、陈述性质及来源范围。

优先补充原文明确提供的镀液/基底、共同添加剂、各自浓度、pH、温度、电流密度、样品阶段、对照和结果基准。结果已有条件时先核对，不重复生成；缺失时先看相关材料段、表格或相邻来源，不能把整篇配方无差别附到每条结果。

具体边界：

- 低浓度加速与高浓度抑制分别保留适用范围，不能合成普遍作用。
- 协同体系、先后加料、Co-free溶液与含Co电极分别表达，不能跨实验组拼条件。
- 无实验/样品分组依据时暂保留事实级条件，不自动建立完整experiment/run/sample本体。
- 原始数值、单位、比较基准保留。只做明确可逆的单位换算，不把不明单位、浓度基准或定性趋势强转数值。
- 观察、计算、作者解释和综述转述保持分离。机理解释可以保留并检索，不改成实验测得事实。
- 对相反结论先检查体系、浓度与阶段，再记录冲突候选，不能多数投票或选择更符合模型常识的一条。
- 未定身份可以作为有原文锚点的提及端点；依赖盐型/电荷等未确定信息的关系保持待审，不自动借用另一个身份的证据。

模型只回显输入任务索引，输出名称、角色、条件/结果及连续原文片段；程序生成持久ID、位置和边。每次输入只包含同篇相关事实、有限实体候选和必要原文，不注入整个图谱或完整类型注册表。

### P2/P3：样本与验收方法

开发6篇12块，验收另留4篇8块；覆盖影响、吸附、测量、机理/开放陈述、协同/浓度分组、盐/聚合物规格、表格或方法条件。优先电镀添加剂材料，至少包含一次配位与吸附边界检查。

先检查历史关系试抽与本轮开发清单，再选择未用于本轮关系提示调整的验收材料；这些文献可能已被历史全库模型处理过，不能称为从未见过的材料。选择理由、来源哈希、重点核验点和完整块关系/条件参考清单必须在调用前保存。

完整块参考同时检查遗漏和误抽；自动通过记录也抽查。分开报告旧基线、模型原始输出、规则处理、AI核验、主审可合入集，不用主审修完后的结果冒充自动准确率。验收样本一旦用于提示调参，就转为开发集，并从预算余额另留验收材料。

P3放行闸门：可合入集没有已知的错端点、反向边、配位误当吸附、跨组条件串接、解释改成观测或无原文支持；重点参考关系/条件遗漏均有补充或明确保留原因。结构与引用必须通过。原始模型错误如实计数，不要求自动输出完美；没有专家金标准时不宣称全库精确率或召回率。

缓存键包含模型、提示、来源、处理逻辑和任务指纹；原始响应、解析结果、补丁、失败及恢复分开保存。预算达到上限、来源证据不足或语义无法判断时保留待审项，不为清零追加无边界调用。
