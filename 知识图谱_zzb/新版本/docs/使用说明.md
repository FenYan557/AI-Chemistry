# 当前v2知识图谱使用说明

适用版本：kg-v2-repaired-20261022-r1。计数见[当前版本说明](../README.md)，人工核验见[审核说明](../../人工核验/审核说明.md)。

## 数据层

- `knowledge_graph.json`：documents为文献，blocks为已收录原文，mentions为逐次提及，facts为参与者、关系、条件、结果及证据。entities/edges为派生视图，不要求每条事实都有二元边。
- `entity_graph.json`：concepts为归一概念，mention_to_concept连接提及，document_entities保留篇内对象，contextual_facts对应原始事实。提及数不是去重实体数。
- `relation_context.json`：6条独立补充关系，保留方法、分组、数值及限定语，与事实重复的内容不能当作多份独立证据。

实体归一不代表实验条件相同。否定、推测和转述范围不能省略；共同条件仅适用于明确绑定的组。

## 检索与引用

在新版本目录运行：

```powershell
python -X utf8 scripts/entity_resolution_retrieval.py "thiamine adsorption" --limit 8 --output "$env:TEMP\kg_v2_context.json"
```

S类为事实，R类为补充原文，C类为补充关系。references提供事实ID、文献ID、原文块及引句定位。共现不能自动证明关系。默认按CURRENT加载；输出的身份、单位待核及语义限定应继续保留。

## 精确查看与校验

```powershell
python -X utf8 scripts/answer_context.py knowledge_graph.json --fact "f:e6fb11f4a0257b0c" --audit --output "$env:TEMP\kg_v2_fact.json"
python -X utf8 scripts/verify_graph.py
```

完整性检查包括指纹、结构、计数、实体映射和补充关系引用，不访问网络或备份，也不授予专家审核状态。

## 原文核验

人工审核表覆盖5844条事实，但未包括全部归一结构、原文全文及6条独立补充关系。按文献标题与引句查PDF；解析器page可能与PDF页码不同。document.source_file可能指向清洗文件，不是PDF路径。

`registry/source_corrections.json`记录原OCR块与核验摘录映射；`registry/source_conflicts.json`记录已知原文冲突；`docs/source_verification/`保存部分页面图片。原PDF不随图谱交付。

## 更新

`construction/`保留当前构建契约和合并门禁，并非全部历史流水线。更新前留快照，明确增量，更新数据和派生图后同步CURRENT与manifest。私有配置`.local/`不提交；备份只作本机追溯。
