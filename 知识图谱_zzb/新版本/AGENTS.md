# 文献知识抽取的固定凭据约定

- 用户已指定：本目录及其后续文献知识抽取，使用 `.local/llm_extraction.json` 中的独立 Key。默认模型也从该文件读取。
- 正式抽取入口为 `scripts/extraction_llm.py`，复用 `scripts/extraction.py` 的提示、精简契约、原文定位与导入校验。
- 该约定针对文献知识抽取；不得将抽取请求改走 A2lab-key、Claude Code 启动器、Hub 或其他环境变量凭据。配置缺失或服务失败时报告原因，不自动替换 Key。
- 不打印、提交、复制或作为交付物展示凭据文件；检查配置只输出字段是否填写。`.local/` 必须保持 Git 忽略。
- 修改默认模型应基于同来源片段的实际可调用性、结构校验和语义核查；服务商模型列表仅作为候选，不保证可用、真实上游身份或价格。
- 抽取只记录文献内容，模型推断和候选建议放在回答阶段。新文献增量处理，不覆盖已有来源事实。
