# 新 Schema 实施计划 v0.2：混合精简与角色选择题

日期：2026-10-20。状态：修订计划，先供审阅；本轮不继续扩展实现。依据：用户指定的《旧版Schema混合精简方案_v0.md》、已有讨论，以及“物质消歧暂缓、L2角色考虑枚举选择”的最新要求。

## 1. 本轮范围的调整

目标：在旧版五层逻辑结构上精简出能映射文献、保留条件与证据的初版。五层是理解结构的方式，不要求五层中的每个概念都成为独立节点。

近期实施：
- 来源锚点、观测、实验/运行、物质与研究对象、断言及证据的最小表达。
- 角色枚举选择、条件性角色绑定、开放关系的定义与归一。
- 旧试跑到新结构的映射、必要校验和小范围重新抽取。

暂缓：
- 化学别名跨篇消歧、结构同一性判断、PubChem/ChEBI自动匹配与实体合并。
- 自动冲突裁决、共识聚合、推荐窗口、全量48篇事实抽取、BERT训练与模型全面对照。
- 不把已登记模型、规划中的算法或可运行格式描述成已验证的领域效果。

仍保存物质原名、文献内局部ID和原文位置；已由作者明确给出的别名可作为原文记录保留，不实施专门消歧流程。局部ID不使用InChIKey或规范化名称冒充已确认的全局身份。

## 2. 对参考稿的采用与修正

| 参考思路 | 本计划决定 |
| --- | --- |
| 五层骨架 | 采用为逻辑结构，减少强制物化层次 |
| Document与Block保留，图表公式不各建一套节点 | 采用；但表格证据保留table_id、行列及表头/脚注，不能只剩整表文字 |
| Observation保留 | 采用，原值原单位保留；缺失单位限制比较，不自动删除数值或改成方向 |
| Experiment/Run保留 | 适用于可区分系列及条件组合的材料；不强迫综述、机理说明、未来工作虚构Run |
| AdditiveUsage改使用关系 | 采用；使用关系记录物质、角色、浓度、加入顺序、条件范围和证据，必要时可被单独引用 |
| Role改枚举 | 旧版已经是枚举，本轮重点是让选择流程及证据绑定可执行 |
| Parameter不单独建节点 | 沿用旧版已有的注册表/属性方向，不重复声称为新精简贡献 |
| Feature合并到Indicator | 不采用；几何/孔型/样品对象与测量指标含义不同，保留区别 |
| Motif等按低频删除 | 不采用频次作为唯一标准；先作字段或候选，关键结构信息不能因样本少而丢弃 |
| PubChem锚定与InChIKey全局ID | 按用户最新指示暂缓，不作为初版准入条件 |
| Claim与EvidenceLink保留，Conflict/KnowledgeUnit后置 | 采用；EvidenceLink可先是结构化证据记录，不要求额外图节点 |
| 预计12—14类、15—20边 | 仅作参考量级，不设凑数指标；实现后按独立类型、枚举和字段分别计数 |

参考稿中“强制UCUM”的判断不直接沿用：已查旧配置要求自有单位词表，并非明确要求UCUM编码。新版本仍放宽原始记录，规范单位在后处理阶段产生。

## 4. L2功能角色：按证据作枚举选择题

### 4.1 选择对象与选项

选择对象是“某物质在某Run/使用语境下的功能角色”，不是给Chemical永久贴标签。它也不同于事实参与者的agent、measured_object等语义角色，两个字段分开。

第一版候选选项：
- accelerator：加速剂；
- suppressor：抑制剂；
- leveler：整平剂；
- carrier：载体类功能角色；
- brightener：光亮剂；
- other：原文明确角色不在上述清单，保存role_raw；
- unknown：当前证据不足，不能判断。

这是初始受控词表，不是已证明完备的领域分类。other用于容纳缓蚀等清单之外的明确角色，后续有足够实例再讨论是否升为独立选项。carrier不能仅凭普通“载体”字面或主介质身份自动选中。

### 4.2 作答规则

1. 输入包括物质原文、所属Run/体系和相关证据段，不只给一个化学名称。
2. 先定位作者明确角色及作用描述，再选择；不得用物质常识代替当前实验依据。
3. 允许多个有证据的角色。若角色分别属于不同浓度、阶段或体系，拆成不同使用记录，不输出脱离条件的多选结果。
4. 每项选择附role_raw、证据位置、适用条件、role_basis和review_status。
5. role_basis区分author_explicit、effect_inference、unknown；由作用方向推测的角色先列候选，不当作作者明确角色。
6. 没有依据选unknown；unknown不与已确定选项混填。other必须保留原始角色及出处。
7. 加速/抑制的指标对象须明确，不能把提高电导率自动映射为电沉积加速。
8. 未来工作、假说或综述转述保留陈述性质；选择正确选项不等于角色已被实验验证。

### 4.3 需要验证的例子

- ADO在低浓度下加速、高浓度下抑制：分别绑定条件；作者称其整平剂的表述另保留，不相互覆盖。
- 只写“可能改善性能”：不强制选择accelerator或brightener。
- CMP原文明确缓蚀角色：初期可用other＋原文角色，不能强塞为电沉积suppressor。
- 缺少角色证据：unknown，物质记录仍可保留。
- 同一使用语境确有多个明确角色：允许多选并逐项给证据。

以上是计划验收例，不是本轮新增的抽取结果。

## 5. 关系与抽取方法

- 物质和事件的记录格式相对稳定，应用关系开放提出候选。
- 候选关系有原始表达、上下文定义、参与者、条件和来源；按EDC式思路检索与判断等价，保留归一映射和不合并理由。
- 不因新谓词未注册就丢弃原文事实；候选与规范关系分区保存。
- AutoSchemaKG/EDC等框架仍为方法候选，不在未复现前写成已经采用或已经优于旧版。
- 角色选择题可用于LLM提示；未来有标注也可形成分类标签。当前不训练BERT。
- 规则检查负责枚举、引用、条件归属和单位状态一致性，不将格式通过当作化学语义正确。

## 6. 执行顺序与交付

### A. 调整现有初版
保留已生成文件，标记早期通用协议为过渡状态；暂停external_lookup及身份链接扩展。生成“现有文件→混合精简结构”的迁移对照，不覆盖旧版和讨论。

### B. 实现骨架、字典与角色选择协议
交付Schema、角色词表、候选关系字典、选择提示词及最小记录示例。硬约束主要防格式损坏、引用不存在及自相矛盾的状态；缺条件/单位和新关系允许保留并标记。

### C. 小范围映射与一次有界抽取
复用3篇4块，逐项映射旧试跑58个mention和18条候选事实。复合事实允许拆分，但保存源ID和对应表。漏抽与原候选本身错误分别列明，不将18条当作完整金标。必要时补查已有六篇样本中的几何对象和计算结果。

先完成本地映射与检查，再安排一次短提示的角色选择/抽取任务；不整库调用模型，不反复生成长方案。

### D. 验收与说明
输出：结构简明说明、机器Schema、字典/角色选项、映射样例与来源对照、校验和必要测试、问题与用量记录。

检查：来源可定位、低/高浓度不混合、不同阶段结果归属正确、未来设想不变成已发生事实、未知/其他角色合法、表格可定位单元格、新谓词可保存。

验收报告只说明表达和程序检查结果，不报告未经标注的准确率、全库覆盖率或消歧率。
