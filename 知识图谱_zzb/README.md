当前包含48篇文献、3720个原文块、5892个概念、5844条事实、2902条图边和6条独立补充关系。事实与图边统计口径不同。审核表覆盖全部事实，但不覆盖全部底层结构与独立补充关系。

`新版本/`是当前交付；`人工核验/`只有一个审核工作簿；`讨论/`为历史方案。`备份/`和`新版本/备份/`是本机历史与试验，不参与运行、不随本次提交上传；已提交的历史可通过Git追溯。未验收候选不属于当前版本。

`.local/`为私有配置，不上传。原PDF不随图谱交付，本机PDF库在上级`知识图谱所需文献/分类文献库/`。完整性检查通过不代表知识全部正确或语料无遗漏。
