# 阶段一：补足原材料缺陷

冻结 48 篇、10,975 个修复块，与 MinerU 原始内容块数量一致。out/repaired/ 的 fields.json 为正则候选，不能当成已确认实验事实。

脚本按自身位置解析路径；原材料位于仓库的知识图谱所需文献/文献提取，书目信息位于 ../inputs/文献清单.csv。不依赖原工作区盘符。

out/report/retention.json 是阶段一对 PDF 文本层的诊断；OCR JSON 是此前执行的记录，本次没有重跑 PDF/OCR。信息保留度说明已按该 JSON 统一。缺陷总账为历史诊断快照，不代表当前剩余缺陷数量。

完整重建命令（仓库根目录，会覆盖阶段一产物）：

    python -m pip install -r 清洗/requirements.txt
    python 清洗/01_补足原材料缺陷/run_01.py

依赖版本取自整理时本机安装环境，不表示本次已重新执行完整 OCR。OCR 模型可能在首次调用时下载。完成后重新运行阶段二和发布验收，并更新诊断文档及哈希清单。从现有阶段一数据复现阶段二无需安装这些依赖。
